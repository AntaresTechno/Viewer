# 构建、测试与运维

## 构建

Windows：

```powershell
.\build.bat
```

手动构建前端：

```bash
cd frontend
npm install
npm run build
```

构建产物位于 `frontend/dist`。生产后端检测到该目录后会同时托管静态资源与 Vue 路由回退。

## 测试

后端：

```bash
cd backend
python -m pytest -q
```

定向测试：

```bash
python -m pytest tests/test_engine_plugins.py -q
python -m pytest tests/test_protocol_plugins.py -q
```

前端：

```bash
cd frontend
npm run build
npx vue-tsc --noEmit
```

生产构建验证打包和 Vue 模板编译；`vue-tsc` 负责更严格的 TypeScript 检查。

## 健康检查

```bash
curl http://127.0.0.1:8000/api/health
```

健康响应中的组件布尔值来自启动时的有效启用集合。若数据库状态已改变但路由尚未重启装配，应以重启后的结果为准。

## 数据备份

默认持久数据位于：

```text
backend/data/viewer.db
```

停止写入后复制数据库文件是最直接的整站备份。若使用自定义 `VIEWER_DATABASE_URL`，应采用对应数据库的原生备份工具。

此外，每个用户可在 WebDAV 页面配置远程备份；该备份面向书架、阅读进度和统计，不替代完整数据库备份。

建议在以下操作前备份：

- 更新代码或依赖。
- 覆盖安装插件。
- 大批量导入或删除来源。
- 更换数据库地址。

## 更新流程

1. 停止当前后端。
2. 备份数据库和外部插件目录。
3. 更新代码。
4. 重新安装后端依赖。
5. 重新构建前端。
6. 启动并检查 `/api/health` 与 `/docs`。
7. 登录后抽查书架、来源、插件状态和阅读进度。

应用启动会创建缺失数据表，并执行代码中提供的附加列迁移。不要在未备份的生产数据库上跳过多个版本后直接验证写入操作。

## 部署建议

- 固定 `VIEWER_SECRET_KEY`。
- 修改默认管理员密码，并停用不需要的账号。
- 使用反向代理提供 HTTPS。
- 不直接向公网暴露调试服务或数据库文件。
- 只安装可信 ZIP 插件；插件 Python 代码与后端进程拥有相同权限。
- 为反向代理设置与导入、WebDAV 和媒体传输相匹配的请求体与超时限制。
- 将数据库、`.env`、协议桥用户配置和备份目录纳入权限控制。

## 常见问题

### 接口返回 404，但插件显示已安装

API 路由在应用创建时挂载。安装、启用或停用带 API 的插件后重启后端。

### 返回 401 或 403

401 表示令牌缺失、过期或用户已停用；重新登录。403 表示账号缺少具体权限或接口要求超级管理员；在权限组中核对命名空间。

### 生产页面没有更新

重新执行 `npm run build`，确认 `frontend/dist/index.html` 的时间已更新，再重启后端并刷新浏览器缓存。

### 来源显示空结果

先查看后端日志。网络超时、远端改版、登录失效和规则异常必须与“合法的空结果”区分。可分别测试搜索、发现分类、详情和目录，定位失败阶段。

### 自定义协议没有唤起 Viewer

在“协议桥设置”检查系统注册状态。注册发生在运行后端的当前系统用户；远程浏览器电脑不会因为服务器完成注册而自动获得 URL Scheme。

### 测试无法创建临时目录

确认测试用户对仓库缓存目录和系统临时目录有写权限。目录权限错误属于运行环境问题，应更换可写路径或修复 ACL，不要以管理员权限长期运行应用规避。
